# CKS Online Jobs

Official-style freelancer registration website for CKS Online Jobs.

## Included sections
- Hero section with business branding
- Freelancer registration form
- Benefits and features
- Why join us
- Contact and FAQ
- Success confirmation page
- Responsive design for desktop and mobile

## Standard registration fields used
- Full Name
- Phone Number
- Email Address
- Password
- Country
- Service Category
- Skills & Experience
- Portfolio / LinkedIn URL

## Run locally
Open `index.html` directly in a browser, or serve the project locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
